Ques 6. Create a User Registration Form with the following fields:
● Full Name
● Email Address
● Password

● Confirm Password
Make all fields required using the required attribute.



Ans 6. <!DOCTYPE html>
<html>
<head>
    <title>Registration Form</title>
</head>
<body>

<h2>Registration Form</h2>

<form>

    Full Name:
    <input type="text" name="name" required>

    <br><br>

    Email:
    <input type="email" name="email" required>

    <br><br>

    Password:
    <input type="password" name="password" required>

    <br><br>

    Confirm Password:
    <input type="password" name="confirm" required>

    <br><br>

    <input type="submit" value="Register">

</form>

</body>
</html>
