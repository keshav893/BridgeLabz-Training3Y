Ques5. Design a pricing table with three pricing plans: Basic, Standard, and Premium.
Requirements:
● Use flexbox or grid to create three equal columns.
● Add a hover effect on each plan that slightly enlarges the box and changes background
color.
● Use CSS transitions for smooth hover animations.
● Each plan should have:
○ A heading (plan name)
○ A list of features
○ A price section
○ A button (styled link using <a>).
● Use different border styles or colors to highlight the most popular plan.
● All boxes should maintain equal height even when text varies.
