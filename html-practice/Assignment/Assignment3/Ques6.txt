Ques 6. Create a CSS-only photo gallery layout with at least 6 images.
Requirements:
● Use flexbox or grid to display images in multiple columns.
● When hovered, each image should:
○ Slightly scale up (transform: scale(1.1))
○ Show a caption overlay using position: absolute and opacity.
● Ensure that the gallery is responsive and adjusts image count per row based on screen
width.
● Use CSS box-shadow and border-radius to make images look clean and modern.
