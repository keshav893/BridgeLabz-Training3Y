Ques 1. Create an HTML file that embeds a YouTube video using an <iframe>.
Set the width and height using only percentage values (not pixels) to make it adjust when
resizing the browser.


Ans 1. <!DOCTYPE html>
<html>
<head>
    <title>YouTube Video</title>
</head>
<body>

<h2>YouTube Video</h2>

<iframe
    width="80%"
    height="60%"
    src="https://www.youtube.com/embed/dQw4w9WgXcQ"
    title="YouTube Video">
</iframe>

</body>
</html>
