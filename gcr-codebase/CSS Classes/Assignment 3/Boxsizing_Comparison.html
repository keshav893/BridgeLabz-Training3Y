Box-Sizing Comparison

Understanding how CSS calculates an element's width

1. Content-Box

Content-box
Width: 100%
Padding: 25px

The declared width applies only to the content. Padding and borders are added outside it, so the total rendered width becomes larger.

2. Border-Box

Border-box
Width: 100%
Padding: 25px

The declared width includes content, padding, and borders. The total rendered width stays within the specified width.

Key Difference

With content-box, total width equals content width + left and right padding + left and right borders.

With border-box, total width already includes padding and borders. This makes layout sizing easier to manage.
