CSS Learning Overview

Filters

CSS filters change the visual appearance of images and other elements.

filter: grayscale(100%);

Typography

Use responsive font sizes to keep text readable on different screen sizes.

font-size: clamp(1rem, 3vw, 2rem);

Media Queries

Media queries apply styles based on viewport dimensions and other device conditions.

@media (max-width: 750px) { ... }
