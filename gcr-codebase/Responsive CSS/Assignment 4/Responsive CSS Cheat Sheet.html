Responsive CSS Cheat Sheet

Quick notes for common responsive CSS concepts

Filters

Apply visual effects such as blur, grayscale, and sepia.

filter: grayscale(100%);

Media Queries

Apply CSS rules when the viewport matches a condition.

@media (max-width: 700px) { ... }

Responsive Design

Make layouts adapt to mobile, tablet, and desktop screens.

width: 100%; max-width: 900px;

Typography

Scale text using flexible units and minimum/maximum sizes.

font-size: clamp(1rem, 3vw, 2rem);

Flexbox

Align items in a row or column with flexible spacing.

display: flex; gap: 16px;

CSS Grid

Create two-dimensional rows and columns.

display: grid; grid-template-columns: repeat(2, 1fr);
